Nightreign Map Patterns

Last updated for Elden Ring Nightreign app ver 1.03.2

Map patterns by Nightlord

Each base game Nightlord has 40 map patterns for regular expeditions: 20 without any Shifting Earth, plus 5 per base game Shifting Earth. Additionally, each base game Nightlord has 10 DLC patterns which are only accessible in Depth of Night. DLC Nightlords have 60 patterns: 20 without any Shifting Earth, 20 in Great Hollow, and 5 per base game Shifting Earth.

  • Gladius (Tricephalos)
  • Adel (Gaping Jaw)
  • Gnoster (Sentient Pest)
  • Maris (Augur)
  • Libra (Equilibrious Beast)
  • Fulghor (Darkdrift Knight)
  • Caligo (Fissure in the Fog)
  • Heolstor (Night Aspect)
  • Harmonia (Balancers)
  • Straghess (Dreglord)

Special Events

At most one special event may occur per expedition. They are determined by the map pattern, and each appear with the corresponding Nightlords only:

  • Morgott Invasion: Adel, Gnoster, Heolstor, Straghess
  • Maris Bubbles: Gnoster, Caligo, Heolstor, Straghess
  • Gnoster Plague: Maris, Libra, Heolstor, Straghess
  • Libra Curse: Fulghor, Caligo, Heolstor, Straghess
  • Gladius Invasion: All Nightlords except Gladius (DLC patterns only)
  • Caligo Blizzard: All Nightlords except Caligo (DLC patterns only)
  • Balancers Raid: All Nightlords except Harmonia (DLC patterns only)
  • Frenzy Tower: Gnoster, Libra, Harmonia, Straghess
  • Extra Night Boss: Adel, Fulghor, Harmonia, Straghess
  • Night Horde: Gladius, Maris, Fulghor, Harmonia
  • Meteor Strike: Gladius, Adel, Caligo, Harmonia
  • Walking Mausoleum: Maris, Caligo, Harmonia
  • Difficult Sorcerer's Rise: Gnoster, Libra, Harmonia

Frenzy Towers, Walking Mausoleums, and difficult Sorcerer's Rises are in the map from the start. All other events are configured to occur on either Day 1 or Day 2. The game waits a random amount of time from the start of the day to trigger the event. Event-specific conditions like player positions must also be satisfied.

  • Day 1:
    • DLC events (Gladius, Caligo, Balancers) happen after exactly 5 minutes on Day 1.
    • Other events happen randomly 6-8 minutes into Day 1.
  • Day 2:
    • The Gladius event in Great Hollow happens randomly 1-2 minutes into Day 2.
    • The Gladius event in other maps happens exactly 2 minutes into Day 2.
    • When any Shifting Earth is active, other Night Boss events (italicized above) happen randomly 2-3 minutes into Day 2.
    • With no Shifting Earth, other DLC events (Caligo, Balancers) happen randomly 2-6 minutes into Day 2.
    • With no Shifting Earth, other events happen randomly 2-8 minutes into Day 2.

FAQ

Why are there so few map patterns?

Not sure, but it makes some sense to give newcomers a foothold to learn the map and its bosses if they get stuck attempting any particular Nightlord. It may have been necessary for QA. Still, the lack of pattern variety becomes evident the more you play, especially with speedruns and other challenge runs. Ideally the game should have had >5k patterns, even with limited night bosses per Nightlord. Nightreign's map pattern system has strong fundamentals which future patches hopefully build on, though it does not seem likely at this point.

What is randomized?

A 32-bit random value we can call the expedition seed determines the map pattern (including shifting earth) and the active remembrance when multiple options are available. It is generated only after matchmaking and selecting a target Nightlord.

While second circle locations are set by the pattern, the first circle location is random based on the expedition seed. The first circle's perimeter is placed at a random angle and eligible distance away from the second circle, such that it contains the second circle. The expedition seed also determines the spawn point approach direction, scarab locations, merchant shops, and the presence of cataclysms (camps with Night Invaders).

Random item and buff drops are not seeded in advance. Likewise, various in-game interactions such as special events may occur at per-run random times or locations, which are determined by the host. Crystal placements in Great Hollow are not seeded either.

Can I play other map patterns with mods?

Yes. However, unlike the certified and released game, bugs are more likely. I've created Nightreign Randomizer and Derandomizer which can produce new map patterns with random combinations of camps and bosses, with additional randomization planned. Make sure to use an alternate save file for all mods. To be updated with DLC support.

Can I force a certain map pattern?

Yes, this is the derandomizer part of the randomizer mod. You must use an alternate save file for this as well.
